# Minimal AI Chat App Using API Calls

This project contains a plug-and-play Python web app that connects a clean front-end chat interface directly to an AI API.

## Setup Instructions

1. **Install Dependencies:**
   Install the required packages using pip:
   ```bash
   pip install -r requirements.txt
   ```

2. **Configure Your API Key:**
   Open `app.py` and replace `"YOUR_OPENAI_API_KEY"` with your real OpenAI secret key.

3. **Run the Application:**
   Execute the script to spin up the local server:
   ```bash
   python app.py
   ```

4. **Access the Chat Client:**
   Open your browser and navigate to `http://127.0.0.1:5000` to interact with your assistant.
